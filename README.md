# Gold Phone — Site premium em React + Bootstrap

Projeto conceito criado para a Gold Phone (Campina Grande/PB), com foco em identidade preto + amarelo, presença de marca, vitrine de aparelhos e interações 3D.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

## Onde alterar informações da loja

No arquivo `src/App.jsx`, edite o objeto `STORE` no topo do arquivo. Nele ficam Instagram, WhatsApp, mensagem padrão, endereço e link do mapa.

## Observação sobre imagens de aparelhos

As imagens da vitrine usam URLs públicas oficiais da Apple como referência visual. Antes de publicar comercialmente, confirme a disponibilidade/modelos da loja e, se preferir, substitua pelas fotos oficiais fornecidas pela própria Gold Phone.

## Identidade

A logo fornecida foi preservada e recebeu apenas tratamento técnico de fundo/transparência e ampliação para uso no layout.
